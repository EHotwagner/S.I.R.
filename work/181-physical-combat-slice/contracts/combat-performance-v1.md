# Combat performance workload v1

The representative workload executes 25 units, 12 canonically ordered physical attacks, all four weapon profiles, and soft/hard cover after three warm-up ticks. The stress workload builds 100 canonically ordered units on a two-cell lattice and resolves 50 support-weapon attacks in one authoritative tick; the lattice makes every attack contact a target without multiplying the same area transition across an artificially dense cluster. Both invoke the explicit authoritative `SIR.Simulation.Simulation.runPhysicalTickWithRules Simulation.defaultRules` entry point, whose physical phase resolves each input through `Combat.resolve` and the executable `CombatRules.resolveAttack` package; direct resolver loops do not qualify this contract. The machine-readable definition is `combat-performance-workload-v1.json`, and its SHA-256 is bound into every receipt.

Structural ceilings are 256 trace cells, 256 area cells, 256 recipients, 4,096 facts, and 65,536 bytes per explanation. Environment-qualified Release observation targets are 20 ms for the representative matrix and 50 ms for the stress tick. These are headless authoritative-route observations, not live-compositor evidence.

The generated `sir.physical-combat.performance-receipt/1` receipt records the workload-definition digest, exact clean candidate commit, performance and simulation assembly digests, executable rules package identities, runtime/OS/architecture/CPU host facts, every timing sample and p95, attack accounting, measured trace/area/recipient/fact/canonical-evidence counters, warm-up, and pass/fail. The qualification script refuses a dirty tree; its explicit development override labels the receipt `dirty-development` and is not release evidence. Area cells are derived from each resolved physical input and its effective weapon parameters; all other structural counters come from the authoritative emitted facts and exact `Simulation.eventsBytes` for each resolved attack. Missing/stale identity, a cap breach, unreadable output, or a failed run blocks qualification. Five scripted mutations lower each structural cap beneath the measured observation and must produce a failing receipt.
