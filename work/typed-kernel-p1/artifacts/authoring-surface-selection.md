# P1 authoring-surface selection

Three short sessions exercised the direct record, computation expression, and hybrid helper against the same real rule. All three normalize and compile identically; the decision is therefore based on authoring friction rather than semantic capability.

Selected surface: **hybrid helper**.

The direct record is retained for low-level transformation code. The computation expression is retained for declarations where sequence materially improves readability. The hybrid helper is the skill default because its real-rule migration compiled without call-site correction, keeps the existing `RuleDefinition` recognizable, and still forces identity, provenance, intent, reads, and writes to be explicit.

The complete `sir-author-rule` pilot session is recorded in `skill-session-combat-damage-001.md`.
