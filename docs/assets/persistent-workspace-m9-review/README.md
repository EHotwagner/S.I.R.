# Persistent workspace M9 review

`field-focus.png` is an actual 1440×900 Chromium screenshot of the production
client, generated by `scripts/generate-persistent-workspace-m9-review.mjs`.
`field-focus-geometry.svg` is explicitly a machine-readable measured-geometry
companion; it is not a reconstructed interface or screenshot.

`manifest.json` binds both assets to the production JavaScript and CSS, the
accepted interactive mockup, live `getBoundingClientRect`/computed-style data
at 1440×900, a real 320×900 Chromium reflow audit, and asset hashes. Regenerate
it after any production client or layout change.
